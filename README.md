## 📄 Instructions to Run the Notebook

1. **Download the Dataset**  
   Download the dataset from the [Regensburg Pediatric Appendicitis Dataset](https://archive.ics.uci.edu/dataset/938/regensburg+pediatric+appendicitis) and place it in the `pediatric/` folder of this repository.

2. **Run the Notebook**  
   Open the Jupyter notebook and **run only the first two sections**:
   - **Data Loading**
   - **Image Preprocessing**

   > ⚠️ You can skip the intermediate sections (preprocessing, validation, etc.) and go directly to the **Multimodal Fusion** section after image preprocessing.
